## 1. The Multi-Scale Teleological Hierarchy

Complex intelligence cannot operate with a single flat goal vector. Real-world tasks span multiple temporal and conceptual scales. ICIA structures intention into a **Differentiable Teleological Tree**:

```
                         [ MACRO-INTENTION I_macro ]
                          (Invariant Mission & Horizon)
                                      │
                 ┌────────────────────┴────────────────────┐
                 ▼                                         ▼
        [ SUB-INTENTION I_sub_1 ]                 [ SUB-INTENTION I_sub_2 ]
        (Milestone 1: Clear Obstacle)             (Milestone 2: Reach Terminal Target)
                 │                                         │
        ┌────────┴────────┐                       ┌────────┴────────┐
        ▼                 ▼                       ▼                 ▼
   Micro-Action 1    Micro-Action 2          Micro-Action 3    Micro-Action 4
```

### 1.1 Formal Hierarchy Levels
1. **Level 2 — Macro-Intention ($\mathcal{I}_{\text{macro}}$):**
   Slow-timescale invariants (e.g., global objective, safety constraints $\mathcal{C}_{\text{global}}$, total computational budget $\mathcal{R}$). Updated only upon major environmental phase shifts.
2. **Level 1 — Sub-Goal Manifold ($\mathcal{I}_{\text{sub}}$):**
   Intermediate-timescale milestones generated by the decomposition operator:
   $$\{\mathcal{I}_{\text{sub}}^{(1)}, \dots, \mathcal{I}_{\text{sub}}^{(m)}\} = \Phi_{\text{decomp}}(\mathcal{I}_{\text{macro}}, \mathcal{B}_t)$$
3. **Level 0 — Micro-Execution Stream ($A_t$):**
   High-frequency primitive state updates and action emissions conditioned on the currently active sub-goal.

## 2. Dynamic Constraint Re-routing & Impasse Resolution

### 2.1 The Problem of Autoregressive Inertia
In standard autoregressive Transformers, the generation of tokens is conditioned on the entire context buffer:
$$p(x_t \mid x_1, \dots, x_{t-1})$$
If steps $x_1, \dots, x_{t-1}$ were executed towards path $A$, all recent activations and KV-cache states reflect path $A$. When an environmental constraint suddenly blocks path $A$ at step $t$, the Transformer suffers from **Autoregressive Inertia**: it continues sampling tokens consistent with path $A$ because its context buffer is dominated by that history. Clearing this inertia requires either manual prompt clearing or extensive penalty mechanisms.

### 2.2 The ICIA Closed-Loop Impasse Pivot
In ICIA-v2, the system does not rely on passive context continuation. State updates are conditioned on the active sub-goal and verified by the discrepancy tensor:

```
[ STEP t: Unexpected Obstacle C_new observed ]
                      │
                      ▼
[ REALITY DISCREPANCY SPIKE: ||E_t|| > θ_impasse ]
                      │
                      ▼
[ SUB-GOAL INVALIDATION: Invalidate I_sub_active ]
                      │
                      ▼
[ RE-ROUTING OPERATOR: Φ_reroute(I_macro, C_new, B_t) -> I_sub_new ]
                      │
                      ▼
[ IMMEDIATE PIVOT: Action A_{t+1} satisfies C_new in 1 Step ]
```

### 2.3 Mathematical Update Rule for Re-routing
When an environmental constraint violation or obstacle is detected:
$$\mathcal{E}_{\text{constraint}}(t) = \sum_{j} \text{ReLU}\left( c_j^{\text{new}}(S_t) \right) > 0$$

The impasse signal triggers an instantaneous projection of the teleological state:
$$T_t \longleftarrow \mathbf{P}_{\Omega_{\text{new}}}(T_t) = T_t - \sum_j \frac{\text{ReLU}(c_j^{\text{new}}(T_t))}{\|\nabla c_j\|^2} \nabla c_j^{\text{new}}(T_t)$$

Because this projection occurs directly in latent state space (rather than through sequential token emissions), **the pivot occurs in exactly 1 step**, eliminating autoregressive inertia entirely.
